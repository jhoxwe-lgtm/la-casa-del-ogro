CENTRO DE CONTROL · SOLO ADMINISTRADOR

Administración completa y pruebas manuales

Todas las operaciones se realizan sobre la misma base SQLite que utiliza la aplicación principal. Los cambios se reflejan en Resumen y en los módulos normales. Las acciones destructivas requieren confirmación y se registran en la bitácora.

Alcance de las operaciones

Crear una habitación genera automáticamente su espacio monitorizado y un sensor simulado. Desactivar una habitación o usuario la retira de la operación sin borrar su historial. Los sensores con lecturas también se desactivan en vez de eliminarse.

La disponibilidad mensual del 99 % (RNF-03) y la usabilidad observada (RNF-04) requieren evidencia específica; una acción desde este panel no sustituye esas mediciones.

Actualizar la aplicación oficial

Al finalizar cambios, vuelve a cargar los módulos para comprobar que el menú principal muestra los mismos datos.

Agregar habitación

Al crearla también se registra el espacio monitorizado y un sensor simulado para poder probar RF-06, RF-14, RF-15 y RF-16.

Editar habitación

Eliminar solo está disponible si la habitación no tiene historial. Si tiene reservas, limpiezas, lecturas o alertas, puedes desactivarla para conservar la trazabilidad.

Preparar estado de habitación (RF-04 / RF-05)

El estado ocupada se demuestra mediante una reserva y su check-in; no se fuerza manualmente para evitar inconsistencias.

Registrar huésped (RF-03)

Editar o eliminar huéspedes

No se puede eliminar un huésped mientras tenga reservas asociadas. Elimina o cancela primero la reserva correspondiente.

Crear reserva (RF-01 / RF-02)

Editar o eliminar reservas

Las reservas en curso se cierran con check-out para conservar la historia del estado de la habitación.

Crear usuario (RF-08 / RF-09)

Editar usuario, rol, acceso o contraseña

No puedes desactivar tu propia sesión ni quitar el último Administrador activo. Los usuarios con operaciones históricas deben desactivarse, no eliminarse.

Registrar sensor en un espacio

Cada espacio admite un único sensor activo. Puedes desactivar el actual antes de asociar uno nuevo.
